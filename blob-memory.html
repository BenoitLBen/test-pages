Chrome Blob Pinning & Memory Controller Test

Demonstrates whether URL.createObjectURL(blob) can cause unbounded browser memory, or if Chrome's BlobMemoryController bounds RAM and pages data to disk.

How to Observe What Chrome Does

  • Step 1: Open Chrome Task Manager (press Shift + Esc). Find the "Browser" row and the "Tab: Chrome Blob Pinning..." row.
  • Step 2: Open chrome://blob-internals in a separate tab.
  • Step 3: Click "Start Allocating Blobs" below.
  • Notice: The Tab (Renderer) process memory stays low because JS references to the data are released after each yield. The Browser process memory climbs until it hits Chrome's in-memory limit (~2 GB on 64-bit desktop, or much lower on Android), at which point Chrome pages the blobs to disk files and stops memory growth!
