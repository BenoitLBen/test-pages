CoreAnimation Backdrop Filter Test Suite

Visual verification and test cases for macOS delegated compositing backdrop filter support.

1. Boundary Bleed Test

Verifies that the gaussian blur is strictly constrained to the element's rectangular bounds and does not bleed into the outer region. Pass criteria: sharp outer checkerboard up to the 1px red marker.

Tests CALayer.mask & inputRadius

2. Border Radius & Corners Test

Exercises rounded corners (small 8px, medium 24px, large 50px, pill/capsule 9999px, and circle 50%) to verify that CoreAnimation layer mask cuts the blur along curved boundaries.

Tests SkRRect & backdrop_filter_bounds

3. Zoom & Retina Scale Test

Calibrates blur radius behavior when zooming in (Cmd+) or viewing on high-DPI Retina screens, ensuring blur radius is divided by tree scale factor rather than growing quadratically.

Tests scale_factor_ normalization

4. macOS Glassmorphic Interface

A full macOS-style floating frosted glass window over an animated high-contrast particle canvas to evaluate real-time dragging performance, frame rates, and visual smoothness.

Tests CABackdropLayer delegated compositing

How to Verify Delegated Compositing via Tracing:

  1. Launch Chromium with: --enable-features=CoreAnimationRenderer
  2. Open chrome://tracing in a new tab.
  3. Record a trace with category viz selected.
  4. Interact with one of the test pages above.
  5. Stop tracing and search for OverlayProcessorMac or the instant trace events to verify that the RenderPassDrawQuad is promoted to a CALayer overlay.
