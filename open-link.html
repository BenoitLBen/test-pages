How to Open Links in a New Tab

Learn the HTML target="_blank" attribute, essential security features like rel="noopener", and JavaScript methods.

Method 1: HTML Tag Declarative

HTML Standard Link

Uses the target="_blank" attribute directly on an anchor tag.

<a href="https://wikipedia.org"
  target="_blank"
  rel="noopener noreferrer">
  Visit Wikipedia </a>

Method 2: JavaScript Programmatic

JavaScript window.open()

Programmatically triggers a new browser tab upon user action or event execution.

window.open(
  'https://github.com',
  '_blank',
  'noopener,noreferrer'
);

Critical Security: Why Use rel="noopener noreferrer"?

Avoid common tab-nabbing vulnerabilities when using target="_blank".

noopener

Prevents the target page from accessing window.opener property, stopping malicious redirects of your original tab.

noreferrer

Prevents passing HTTP Referrer header information to the new page for privacy and also implies noopener in older browsers.

Accessibility

Always inform screen readers and users visually that a link will open in a new window using an icon or accessible text.
